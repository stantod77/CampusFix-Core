PRIORITY CALCULATION FORMULA
═══════════════════════════════════════════════════════════════════════════════

    Priority Score = Ticket Severity (1-10) * Building Criticality (1-10)
    
    Range: 1-100
    
    Examples:
     Severity 10 * Criticality 10 = 100 (Fire alarm in server room)
     Severity 9 * Criticality 10 = 90   (Network down in server room)
     Severity 5 * Criticality 2 = 10    (Leak in dorm room)


TRADE ASSIGNMENT LOGIC
═══════════════════════════════════════════════════════════════════════════════

    Ticket Category  ->  Assigned Trade
    ────────────────────────────────
    HVAC             ->  HVAC Tech
    Plumbing         ->  Plumber
    Electrical       ->  Electrician
    IT               ->  SysAdmin
    Furniture        ->  General Maintenance

USAGE EXAMPLES
═══════════════════════════════════════════════════════════════════════════════

1. Default (Local Database)
   $ ./bin/campusfix_dispatcher
   
2. Demo Mode (No Database)
   $ ./bin/campusfix_dispatcher --demo-only
   
3. Custom Database
   $ ./bin/campusfix_dispatcher --database my_db
   
4. Remote Server
   $ ./bin/campusfix_dispatcher \
     --host prod-db.example.com \
     --user admin \
     --password secret \
     --database production_db
   
5. Configuration File
   $ ./bin/campusfix_dispatcher --config database.conf
   
6. Quiet Mode (Batch)
   $ ./bin/campusfix_dispatcher --demo-only --quiet
